Keep a copy somewhere else

Backups on the same laptop don't survive a lost or broken laptop. Two options:

  • Drag the backups folder into Dropbox, iCloud Drive, or Google Drive every so often — or point jobpilot at a synced folder by setting JOBPILOT_DATA_DIR.
  • Email yourself the spreadsheet once a week. It's small, and a dated email is its own timestamped record if an agency ever asks.

Sync the backups rather than the live database — cloud services can corrupt a database file that's being written while it syncs.

Restore from a backup

Replaces everything currently in jobpilot with the contents of a backup file (jobpilot-YYYY-MM-DD.db). Your current database is saved alongside the backups first, so this is reversible.
